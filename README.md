# AI Virtual Career Counsellor

## Introduction
This project helps students explore career options based on their favourite subjects and interests.

## Features
- Five subject categories
- Career recommendations
- Required skills
- Four-step career roadmap
- Streamlit user interface
- PDF report download

## Technologies Used
- Python
- Streamlit
- FPDF2

## Project Domain
Artificial Intelligence and Machine Learning

## Note
This is a rule-based career recommendation prototype.
